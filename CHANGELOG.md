# Журнал изменений (Changelog)

Все значимые изменения в проекте Server Setup документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено]

### Исправлено
- **Модули v2.2.0 не были подключены**: `server-setup.sh` загружал только 2 модуля, пункты 2–8 главного меню были заглушками. Теперь подключаются все модули, а главное меню строится из манифестов `@menu.manifest` (сортировка по ORDER, группировка по GROUP)
- Парсер манифестов обрезал строку на первой `)` — заголовки со скобками (`Фаервол (UFW)`) ломали поля пункта меню
- Конфликт клавиши `2` в главном меню (зеркала APT и пользователи): зеркала перенесены на `m`
- Вызов несуществующей функции `printf_error` при неверном выборе в 9 модулях
- `ask_yes_no` игнорировал ответ по умолчанию — Enter приводил к бесконечному повтору вопроса
- `safe_read` не сообщал об EOF: при закрытом stdin (Ctrl+D) меню зацикливалось
- `mirror_check.sh` перезаписывал глобальный `BACKUP_DIR` и функцию `_update_package_lists` из других модулей
- **SSH**: риск потери доступа — проверка наличия пользователей с SSH-ключами перед отключением паролей/root, открытие нового порта в UFW до перезапуска, подтверждение входа в новом терминале с автоматическим откатом; удален override `ExecStart=sshd -D -p` (терял `$SSHD_OPTS`); исправлено определение текущего порта (`sshd -T`) и проверка прослушивания (`:22` совпадал с `:2222`); для `ssh.socket` убран конфликт двойного `ListenStream`
- **2FA**: секрет и QR-код не выводились (`google-authenticator -q`) — пользователь не мог настроить приложение; добавлен показ QR/аварийных кодов, проверка входа и откат; после кода больше не запрашивается пароль, если вход по паролю отключен
- **UFW**: при включении открывался порт `22` вместо фактического порта SSH; добавлена установка UFW, точная проверка существующих правил, защита от закрытия порта SSH, `ufw reload` после смены IPv6
- **Fail2Ban**: jail `sshd` не запускался на Debian 12+ без rsyslog (добавлен `backend = systemd`); использовался неверный порт SSH; `banaction = ufw` и jail `ufw-probes` включаются только при наличии UFW
- **Пользователи**: валидация ключей отвергала ECDSA и FIDO (`sk-*`) ключи; сгенерированный пароль записывался в лог; добавлены проверка имени пользователя и установка пакета `sudo` при его отсутствии
- **Автообновления**: включение фактически не происходило (проверялся `50unattended-upgrades`, который есть всегда, вместо `20auto-upgrades`); параметры теперь пишутся в `52unattended-upgrades-local`, а не затирают дистрибутивную конфигурацию
- **Система**: `dpkg-reconfigure locales` запускался через `run_cmd` (вывод в лог) — интерактивный диалог был невидим; добавлена валидация имени хоста; `sysctl -e` не прерывает применение из-за отсутствующих параметров
- **Зеркала APT**: для Ubuntu использовались компоненты Debian; игнорировались deb822-файлы (`debian.sources`, `ubuntu.sources`) — замена зеркала не действовала на Debian 12+/Ubuntu 24.04; больше не отключаются сторонние репозитории (Docker и др.); восстановление из бэкапа восстанавливает и `sources.list.d`
- **Docker**: неверный URL репозитория (codename вместо ID дистрибутива); установка `curl`/`gnupg` при отсутствии; предупреждение об обходе UFW опубликованными портами
- **Tailscale/NetBird**: ключ авторизации записывался в лог; аргументы передаются массивом
- **Бэкапы**: использовалась неопределенная переменная `$USERNAME` (бэкап `/home/root/`); добавлены установка `rsync`, `StrictHostKeyChecking=accept-new`, `rsync -R` для нескольких директорий, валидация расписания cron
- **Swap**: некорректный ввод размера приводил к ошибке арифметики; при изменении размера `/swap.img` удалялся, а запись в fstab оставалась
- **Аудит**: рекомендации Lynis и индекс hardening не извлекались (неверный формат `lynis-report.dat`); неверный подсчет уязвимостей debsecan
- **install.sh**: временная директория не удалялась при ошибке; локальный запуск без TTY ошибочно считался удаленной установкой

## [2.2.0] - 2026-05-03

### Добавлено
- **11 новых модулей** для расширения функциональности:
  - `modules/security/user_management.sh` — управление пользователями (создание, SSH-ключи, sudo)
  - `modules/security/ssh_hardening.sh` — настройка SSH и 2FA
  - `modules/security/firewall.sh` — фаервол UFW (правила, IPv6)
  - `modules/security/intrusion_prevention.sh` — защита (Fail2Ban/CrowdSec)
  - `modules/system/auto_updates.sh` — автообновления (unattended-upgrades)
  - `modules/system/system_hardening.sh` — ядро и система (sysctl, hostname)
  - `modules/network/network_tools.sh` — сетевые инструменты (Docker, Tailscale, NetBird)
  - `modules/system/backup.sh` — бэкапы (rsync)
  - `modules/system/resource_management.sh` — ресурсы (swap, время)
  - `modules/system/audit_cleanup.sh` — аудит и очистка (Lynis, провайдеры)
  - `modules/core/custom_bashrc.sh` — кастомизация .bashrc

### Изменено
- **Улучшение существующих модулей:**
  - `modules/security/system_update.sh` — исправлены UI хелперы, обновлены переменные цветов, меню переведено на `render_menu_items`/`get_menu_action`
  - `modules/security/mirror_check.sh` — аналогичные улучшения для соответствия единому стилю

- **Соблюдение стандартов:**
  - Все модули соответствуют `docs/STYLE_GUIDE.md` и `docs/GUIDE_MODULES.md`
  - Используются функции из `modules/core/common.sh`: `info`, `ok`, `warn`, `err`, `ask_yes_no`, `safe_read`, `run_cmd`, `menu_header`, `printf_description`, `printf_menu_option`, `render_menu_items`, `get_menu_action`

### Планируется
- Добавление пользовательского дашборда (dashboard)
- Плагины для виджетов дашборда
- Расширение системы конфигурации (`config/server.conf`)

### Исправлено
- Исправлена кодировка файла `modules/core/common.sh` (удален BOM, исправлен русский текст, отображавшийся некорректно)

## [2.1.0] - 2026-05-03

### Добавлено
- **Реорганизация под архитектуру эталонного скрипта:**
  - Модульная структура с сохранением лучших практик
  - Улучшенное логирование с поддержкой уровней вывода
  - Система аргументов командной строки (`--help`, `--quiet`, `--auto`, `--version`)
  - Глобальные переменные конфигурации (`LOG_FILE`, `REPORT_FILE`, `BACKUP_DIR`, `VERBOSE`)
  - Обработка ошибок через `trap` и функцию `handle_error()`
  - Main flow с последовательным выполнением

- **Новые возможности:**
  - Модуль `modules/core/environment.sh` для определения окружения
    - Определение типа виртуализации (KVM, VMware, Docker и т.д.)
    - Определение провайдера (Hetzner, DigitalOcean и др.)
    - Определение типа окружения (commercial-cloud, personal-vm, bare-metal)
  - Поддержка `tput` для корректного отображения цветов в разных терминалах
  - Новые функции вывода: `print_header()`, `print_section()`, `print_success()`, `print_error()`, `print_warning()`, `print_info()`, `print_separator()`
  - Функция `check_dependencies()` для проверки зависимостей

- **Обновление модулей:**
  - `modules/core/common.sh` — полностью обновлен с улучшенным логированием
  - `modules/security/system_update.sh` — добавлена поддержка `$VERBOSE`
  - `modules/security/mirror_check.sh` — добавлена поддержка `$VERBOSE`

### Изменено
- **Рефакторинг главного скрипта:**
  - `server-setup.sh` — добавлен парсинг аргументов, функция `main()`, обработка `trap`
  - Удалены все упоминания эталонного скрипта из файлов проекта
  - Версию скрипта обновлена до v2.1.0

- **Обновление документации:**
  - `plans/plan.md` — детальный план реорганизации с диаграммой потока
  - Обновлены ссылки на версию в README.md и других файлах

### Исправлено
- Корректная обработка ошибок с использованием `trap ERR` и `trap EXIT`
- Улучшена проверка прав root с понятным выводом
- Исправлена логика тихого режима (`--quiet`)
